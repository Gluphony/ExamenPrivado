# Inventario Tienda

Somos un equipo de tres estudiantes y este es nuestro proyecto para el examen de ciclo de vida. Hicimos un prototipo sencillo para llevar el inventario de una tienda ficticia de artículos de oficina y hogar.

## Cómo abrirlo

1. Abre `index.html` en Edge, Chrome o Firefox.
2. Usa el menú para entrar a Resumen, Productos o Movimientos.

No hay que instalar nada. Los cambios se guardan en el navegador donde abras el proyecto.

## Qué puedes probar

- Ver los productos y las unidades disponibles.
- Buscar productos y filtrar los que tienen pocas existencias.
- Agregar, editar o eliminar productos.
- Registrar entradas y salidas de productos.

Los datos son de ejemplo. El prototipo no usa una base de datos y considera bajo un inventario de 8 unidades o menos.

## Archivos

- `index.html`: página de la aplicación.
- `styles.css`: estilos.
- `app.js`: funciones y datos de ejemplo.
- `propuesta.md`: resumen de la propuesta del proyecto.

## Publicación

El examen pide publicar el prototipo con GitHub Pages. El equipo creará el repositorio y hará la publicación.
